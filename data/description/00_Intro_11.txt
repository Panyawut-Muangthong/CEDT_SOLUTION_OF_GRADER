# 🟦 Key Concepts

## 01 · `#include <iostream>`

The `#include <iostream>` preprocessor directive imports standard input/output stream definitions. It gives your program access to tools like `std::cin` and `std::cout`.

```cpp
#include <iostream>
```

---

## 02 · Why Avoid `using namespace std;`?

In beginner tutorials, you often see:

```cpp
using namespace std; // Not recommended in professional code
```

While it saves keystrokes, **avoid this in real-world code** for several critical reasons:

* **Name Collisions:** The `std` namespace contains thousands of identifiers (like `count`, `min`, `max`, `size`, `data`). If you define your own variable or function named `count`, the compiler cannot determine whether you mean your `count` or `std::count`, causing compiler errors or silent bugs.
* **Header Pollution:** If placed in a header file (`.h`/`.hpp`), `using namespace std;` forces the entire standard namespace into every file that includes that header, breaking encapsulation across the entire project.
* **Readability and Explicit Intent:** Writing `std::cin` or `std::cout` makes it instantly clear to any reader that the identifier belongs to the standard library, not local or third-party code.

---

## 03 · The `main()` Function

Every executable C++ program requires a `main()` function. It serves as the program's starting execution point.

```cpp
int main() {
    // Code executes sequentially here
    return 0; // Signals successful termination to the operating system
}
```

---

## 04 · Semicolons (`;`)

In C++, the semicolon is a **statement terminator**. It tells the compiler where an instruction ends.

* Every variable declaration, assignment, function call, and input/output statement must end with a semicolon.
* Omitting a semicolon produces a compiler error because C++ ignores whitespace and newlines when parsing statements.

```cpp
int age = 18;  // Statement ended with ';'
std::cout << age; // Statement ended with ';'
```

---

## 05 · Standard Input: `std::cin >>`

`std::cin` reads formatted input from the standard input stream (keyboard) and uses the extraction operator (`>>`) to store the value into a variable.

```cpp
int age;
std::cin >> age;
```

If the user enters:

```text
18
```

The integer `18` is parsed and stored inside `age`.

---

## 06 · Standard Output: `std::cout <<`

`std::cout` sends formatted data to the standard output stream (terminal) using the insertion operator (`<<`).

```cpp
int age = 18;
std::cout << age;
```

Output:

```text
18
```

You can also output expressions directly:

```cpp
std::cout << 5 + 5;
```

Output:

```text
10
```

---

## 07 · Formatting Output: `\n` and `\t`

### `\n` — Newline

`\n` shifts the cursor to the beginning of the next line.

```cpp
std::cout << "Hello\nWorld\n";
```

Output:

```text
Hello
World
```

> **Performance Note:** Prefer `\n` over `std::endl`. While `std::endl` inserts a newline, it also forces a buffer flush (`std::flush`), which causes unnecessary performance overhead in I/O-heavy programs.

### `\t` — Horizontal Tab

`\t` moves the cursor to the next tab stop, making it useful for aligning tabular output:

```cpp
std::cout << "Name:\tJohn\n";
std::cout << "Age:\t18\n";
```

Output:

```text
Name:   John
Age:    18
```

# 📝 Complete Example Program

A complete, clean C++ program reading user input and formatting the output without polluting the global namespace:

```cpp
#include <iostream>

int main() {
    int id;
    int score;

    // Read values from standard input
    std::cin >> id >> score;

    // Print aligned report to standard output
    std::cout << "ID:\t" << id << "\n";
    std::cout << "Score:\t" << score << "\n";

    return 0;
}
```

### Example Input

```text
101 95
```

### Example Output

```text
ID:     101
Score:  95
```
